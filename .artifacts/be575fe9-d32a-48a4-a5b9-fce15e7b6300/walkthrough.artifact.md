# Walkthrough - Razorpay Pending Payment Cancellation

I have implemented the logic to automatically notify the backend when a Razorpay payment is cancelled by the user or fails. This ensures the backend can immediately mark the corresponding pending order as cancelled.

### Checkout Flow Enhancement

#### [checkout_screen.dart](file:///C:/Users/pc/StudioProjects/kosmicowellness/lib/screens/checkout_screen.dart)

1.  **State Tracking**: Added `_currentRazorpayOrderId` to the `_CheckoutScreenState` to keep track of the Razorpay order generated by the backend.
2.  **Assignment**: In `_placeOrder`, once the Razorpay order is successfully created on the backend, the ID is stored in `_currentRazorpayOrderId`.
3.  **Automatic Cancellation**: In `_handlePaymentFailure` (which triggers when the user cancels the payment or it fails), the app now calls `ApiService.cancelPendingRazorpayOrder` if an ID exists.
4.  **Cleanup**: The ID is cleared in both `_handlePaymentSuccess` and `_handlePaymentFailure` to prevent duplicate calls.
